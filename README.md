## UC7 — Add Volume Unit (Gallon and Litre)

### Objective
Introduce volume measurement with `Gallon` and `Litre`, supporting comparison and addition.

### Project Structure
```

│   └── Program.cs
└── QuantityMeasurementApp.Tests/
```

### What Was Done
- Created `Gallon` and `Litre` classes
- Conversion: `1 Gallon = 3.78 Litres`
- Comparison and addition between gallons and litres supported
